Agent 发来的每条命令都走同一条路：先过 403，再过 428，最后才到审批台。两个等级只是同一条流水线上的两道闸，不是两套系统。

403 直接拦截→ 428 灵魂三问→ 审批台
403 直接拦截 不弹审批

命中即拒绝，连「同意」这个选项都不给你——看不懂的命令不值得占用你一次判断。改动任意一条都要主密码 + 动态码。

428 灵魂三问 自审 + 审批 …

Agent 必须先回答「我是谁、我在哪儿、我打算干什么」，答完才推手机等你批准。关掉自审只免掉那次问答，审批照样会弹。

手机怎么装证书 / 证书诊断

iOS：设置 → 通用 → VPN 与设备管理 → 安装；再到 通用 → 关于本机 → 证书信任设置 → 对 AgentKeyGuard Root CA 开启完全信任。

Android：设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书 → 选 ca.crt。

Windows / macOS：双击 ca.crt 装到「受信任的根证书颁发机构」；macOS 在钥匙串里设为始终信任。

审批小硬件 构想

一个不经过手机、握在手里的审批终端：带小屏、两个按键和麦克风，按下即通过，按住拒绝可以口述理由。它要解决的不是「方便」，而是让审批重新变成一个物理动作。

这只是一份想法，不是路线图承诺；现在的手机审批与推送不会因此改变。

可以是什么样

  • 形态小遥控器大小，正面一块 1.3 寸屏，拇指区两个按键，顶部留挂绳孔。
  • 通过单击放行；高危请求（428）改成按住确认，避免手指一滑就过了。
  • 拒绝短按直接拒绝；按住录音、松开发送，语音在服务端转成文字，作为拒绝理由回给 Agent。
  • 连接家里插在底座上常供电，出门用电池；断网时至少能看见待办。

怎么接进来

设备不共享管理员会话，而是作为一种独立身份接入：控制台生成一次性绑定链接，设备换取自己的密钥，权限只有「看待审批 / 同意 / 拒绝」，丢了可随时吊销。

每条审批会标注来源（网页 / 手机 / 硬件），和现在的审计是同一条链。
